## 分析内容详细规划

### 第一部分：项目整体架构分析（01_项目整体架构分析.md）
1. **项目整体结构图**
   - 模块划分图
   - 数据流图
   - 调用关系图
   
2. **项目设计理念**
   - 业务驱动的知识图谱构建思想
   - 基于规则的问答系统优势
   - 模块解耦设计原则

3. **技术栈分析**
   - Python3作为开发语言
   - Neo4j作为图数据库
   - py2neo作为Python操作Neo4j的库
   - Aho-Corasick算法用于实体匹配
   - MongoDB用于原始数据存储

### 第二部分：数据准备与知识图谱构建（02_数据准备与知识图谱构建模块分析.md）
1. **数据来源与采集流程**

   - 数据结构化解析

2. **数据预处理分析**
   - `build_data.py`中的数据清洗逻辑
   - 中文分词与实体抽取
   - 数据标准化与映射

3. **知识图谱Schema设计**
   - 7类实体节点（Disease, Drug, Food, Symptom, Check, Department, Producer）
   - 11类实体关系（has_symptom, common_drug, do_eat等）
   - 疾病属性字段（desc, cause, prevent, cure_way等）

4. **图谱构建流程**
   - `MedicalGraph`类设计分析
