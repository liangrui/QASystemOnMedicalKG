## 3. build_entitydict() ([第10-19行](file:///workspace/question_parser.py#L10-L19))

将实体从`{词: [类型]}`转换为`{类型: [词]}`格式。

```python
def build_entitydict(self, args):
    entity_dict = {}
    for arg, types in args.items():
        for type in types:
            if type not in entity_dict:
                entity_dict[type] = [arg]
            else:
                entity_dict[type].append(arg)
    return entity_dict
```

**示例**：
```python
输入: {'感冒': ['disease'], '咳嗽': ['symptom']}
输出: {'disease': ['感冒'], 'symptom': ['咳嗽']}
```

## 4. parser_main() ([第21-90行](file:///workspace/question_parser.py#L21-L90))

主解析流程：
```python
def parser_main(self, res_classify):
    args = res_classify['args']
    entity_dict = self.build_entitydict(args)
    question_types = res_classify['question_types']
    
    sqls = []
    for question_type in question_types:
        sql_ = {'question_type': question_type}
        sql = self.sql_transfer(question_type, entity_dict.get(entity_type))
        if sql:
            sql_['sql'] = sql
            sqls.append(sql_)
    
    return sqls
```

## 5. sql_transfer() - Cypher查询生成 ([第93-179行](file:///workspace/question_parser.py#L93-L179))

### 5.1 查询分类

#### 类型1：属性查询（查询疾病节点属性）
```python
# 查询病因
if question_type == 'disease_cause':
    sql = ["MATCH (m:Disease) where m.name = '{0}' return m.name, m.cause".format(i) for i in entities]

# 查询预防措施
elif question_type == 'disease_prevent':
    sql = ["MATCH (m:Disease) where m.name = '{0}' return m.name, m.prevent".format(i) for i in entities]

# 查询治疗周期
elif question_type == 'disease_lasttime':
    sql = ["MATCH (m:Disease) where m.name = '{0}' return m.name, m.cure_lasttime".format(i) for i in entities]
```

#### 类型2：关系查询（查询节点间关系）
```python
# 查询疾病症状
if question_type == 'disease_symptom':
    sql = ["MATCH (m:Disease)-[r:has_symptom]->(n:Symptom) where m.name = '{0}' return m.name, r.name, n.name".format(i) for i in entities]

# 查询症状对应疾病
elif question_type == 'symptom_disease':
    sql = ["MATCH (m:Disease)-[r:has_symptom]->(n:Symptom) where n.name = '{0}' return m.name, r.name, n.name".format(i) for i in entities]
```

#### 类型3：双向关系查询
```python
# 查询并发症（需要双向查询）
if question_type == 'disease_acompany':
    sql1 = ["MATCH (m:Disease)-[r:acompany_with]->(n:Disease) where m.name = '{0}' return m.name, r.name, n.name".format(i) for i in entities]
    sql2 = ["MATCH (m:Disease)-[r:acompany_with]->(n:Disease) where n.name = '{0}' return m.name, r.name, n.name".format(i) for i in entities]
    sql = sql1 + sql2
```

#### 类型4：多关系合并查询
```python
# 查询疾病推荐药物（常用药+推荐药）
if question_type == 'disease_drug':
    sql1 = ["MATCH (m:Disease)-[r:common_drug]->(n:Drug) where m.name = '{0}' return m.name, r.name, n.name".format(i) for i in entities]
    sql2 = ["MATCH (m:Disease)-[r:recommand_drug]->(n:Drug) where m.name = '{0}' return m.name, r.name, n.name".format(i) for i in entities]
    sql = sql1 + sql2
```
