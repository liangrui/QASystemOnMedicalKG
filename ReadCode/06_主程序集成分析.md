## 1. 模块概述

[chatbot_graph.py](file:///workspace/chatbot_graph.py)是整个问答系统的主程序，负责集成三大核心模块：

- QuestionPaser - 问句解析

## 4. chat_main() - 主问答流程 ([第18-28行](file:///workspace/chatbot_graph.py#L18-L28))

### 4.1 完整流程图
```
用户问题
    |
    ├─→ 分类模块 (classifier.classify)
    |       |
    |       ├─→ 无实体? ──→ 返回默认回答
    |       |
    |       └─→ {args, question_types}
    |
    ├─→ 解析模块 (parser.parser_main)
    |       |
    |       └─→ {sqls}
    |
    ├─→ 搜索模块 (searcher.search_main)
    |       |
    |       ├─→ 无结果? ──→ 返回默认回答
    |       |
    |       └─→ final_answers
    |
    └─→ 拼接回答并返回
```

### 4.2 代码实现
```python
def chat_main(self, sent):
    # 默认回复
    answer = '您好，我是小勇医药智能助理，希望可以帮到您。如果没答上来，可联系https://liuhuanyong.github.io/。祝您身体棒棒！'
    
    # Step 1: 问题分类
    res_classify = self.classifier.classify(sent)
    if not res_classify:
        return answer
    
    # Step 2: 问题解析（生成Cypher）
    res_sql = self.parser.parser_main(res_classify)
    
    # Step 3: 答案搜索
    final_answers = self.searcher.search_main(res_sql)
    if not final_answers:
        return answer
    else:
        return '\n'.join(final_answers)
```

## 6. 完整示例

**用户输入**：
```
感冒有什么症状？
```

**Step 1 - 分类**：
```python
{
    'args': {'感冒': ['disease']},
    'question_types': ['disease_symptom']
}
```

**Step 2 - 解析**：
```python
[
    {
        'question_type': 'disease_symptom',
        'sql': ["MATCH (m:Disease)-[r:has_symptom]->(n:Symptom) where m.name = '感冒' return m.name, r.name, n.name"]
    }
]
```

**Step 3 - 搜索**：
```python
['感冒的症状包括：咳嗽；流鼻涕；发热']
```

**最终输出**：
```
小勇: 感冒的症状包括：咳嗽；流鼻涕；发热
```

## 7. 异常处理与默认回复

**情况1**：没有识别到任何实体

res_classify = self.classifier.classify(sent)
if not res_classify:
    return answer  # 返回默认回复

**情况2**：查询没有结果
```python
final_answers = self.searcher.search_main(res_sql)
if not final_answers:
    return answer  # 返回默认回复
```

## 8. 设计特点

### 8.1 模块解耦
- 三个核心模块相互独立
- 通过结构化数据传递
- 便于单独维护和测试

### 8.2 流程清晰
- 分类 → 解析 → 搜索 三步式处理
- 逻辑直观，易于理解

### 8.3 容错机制
- 多层默认回复机制
- 保证用户体验
