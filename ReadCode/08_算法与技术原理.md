## 1. Aho-Corasick 多模式匹配算法

### 1.1 算法背景

Aho-Corasick (AC) 算法是由 Alfred V. Aho 和 Margaret J. Corasick 于 1975 年发明的字符串搜索算法。

**为什么选择AC算法？**
- 需要同时匹配4.4万+实体词
- 普通正则或遍历匹配效率低
- AC算法时间复杂度为 O(n + m)，n为文本长度，m为匹配数量

### 1.2 算法原理

AC算法由三个核心部分组成：
1. **前缀树 (Trie)** - 存储所有模式串
2. **失败指针 (Failure Link)** - 类似KMP算法的失败函数
3. **输出表 (Output)** - 记录每个节点的匹配结果

### 1.3 算法流程

#### 构建阶段：
```
Step 1: 构建Trie树
- 所有实体词构建成一棵前缀树
- 每个节点代表一个字符

Step 2: 构建失败指针
- 使用BFS按层次遍历
- 失败指针指向最长的可匹配后缀
- 类似KMP的部分匹配思想

Step 3: 构建输出表
- 将失败指针的输出合并到当前节点
```

#### 匹配阶段：
```
初始化: 当前节点 = 根节点
逐个字符处理:
    while 当前节点按字符无法转移:
        当前节点 = 当前节点.fail
    if 存在转移:
        当前节点 = 转移后的节点
        输出当前节点的所有匹配结果
```

### 1.4 复杂度分析

| 阶段 | 时间复杂度 |
|-----|----------|
| 构建Trie树 | O(m)，m为所有模式串总长度 |
| 构建失败指针 | O(m) |
| 匹配过程 | O(n + z)，n为文本长度，z为匹配数 |

## 2. Neo4j 图数据库

### 2.1 属性图模型

Neo4j使用**属性图 (Property Graph)** 模型：
```
节点 (Node):
- 有标签 (Label)，如 :Disease, :Drug
- 有属性 (Property)，如 name, desc

关系 (Relationship):
- 有类型 (Type)，如 :has_symptom, :common_drug
- 有方向 (Directed)
- 可以有属性
```

### 2.2 Cypher 查询语言

Cypher是Neo4j的查询语言，使用ASCII-Art风格语法：

```cypher
// 基础匹配
MATCH (node:Label)
WHERE node.property = value
RETURN node

// 关系查询
MATCH (a:Label1)-[rel:REL_TYPE]->(b:Label2)
WHERE a.name = "xxx"
RETURN a, rel, b
```

### 2.3 项目中的Cypher应用

```python
# 查询疾病属性
"MATCH (m:Disease) WHERE m.name = '感冒' RETURN m.name, m.cause"

# 查询关系
"MATCH (m:Disease)-[r:has_symptom]->(n:Symptom) WHERE m.name = '感冒' RETURN m, r, n"

# 双向查询
"MATCH (m:Disease)-[r:acompany_with]->(n:Disease) WHERE m.name = '感冒' RETURN ..."
"MATCH (m:Disease)-[r:acompany_with]->(n:Disease) WHERE n.name = '感冒' RETURN ..."
```

## 3. 基于规则的问答系统

### 3.1 规则系统 vs 机器学习系统

| 特性 | 规则系统 | 机器学习系统 |
|-----|---------|------------|
| 可解释性 | 高，规则可追溯 | 低，黑盒模型 |
| 实现难度 | 低 | 高 |
| 需要数据 | 少 | 大量标注数据 |
| 覆盖范围 | 有限 | 可能更广 |
| 维护成本 | 规则增多成本上升 | 数据维护成本 |
| 上线速度 | 快 | 慢 |

### 3.2 项目中的规则设计

1. **实体匹配规则**：AC算法 + 最长匹配
2. **问题分类规则**：特征词匹配 + 实体类型
3. **查询生成规则**：问题类型 → Cypher模板
4. **答案生成规则**：查询结果 → 自然语言模板

## 4. 最长匹配策略

### 4.1 问题

当同时匹配到多个实体时，可能存在包含关系：
```
文本: "急性支气管炎"
可能匹配: "急性", "急性支气管炎"
```

### 4.2 解决方案

```python
stop_wds = []
for wd1 in region_wds:
    for wd2 in region_wds:
        if wd1 in wd2 and wd1 != wd2:
            stop_wds.append(wd1)
final_wds = [i for i in region_wds if i not in stop_wds]
```

保留最长的匹配项，删除被包含的短匹配。
