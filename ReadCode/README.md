## 🎯 支持的18类问题

1. **disease_symptom** - 疾病有哪些症状
2. **symptom_disease** - 症状可能是什么疾病
3. **disease_cause** - 疾病的病因
4. **disease_acompany** - 疾病的并发症
5. **disease_not_food** - 疾病不能吃什么
6. **disease_do_food** - 疾病推荐吃什么
7. **food_not_disease** - 什么病不能吃某食物
8. **food_do_disease** - 某食物对什么病好
9. **disease_drug** - 疾病用什么药
10. **drug_disease** - 某药治什么病
11. **disease_check** - 疾病需要做什么检查
12. **check_disease** - 某检查能查什么病
13. **disease_prevent** - 疾病如何预防
14. **disease_lasttime** - 治疗周期
15. **disease_cureway** - 如何治疗
16. **disease_cureprob** - 治愈概率
17. **disease_easyget** - 易感人群
18. **disease_desc** - 疾病描述

## 🎓 学习要点

### 关键技术点

1. **Aho-Corasick算法**
   - 用于高效多模式实体匹配
   - 时间复杂度：O(n + m)

2. **规则系统**
   - 18类问题，18套规则
   - 特征词匹配 + 实体类型判定

3. **知识图谱**
   - 属性图模型
   - Cypher查询语言

4. **管道架构**
   - 分类 → 解析 → 搜索
